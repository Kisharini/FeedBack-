BACKEND SETUP GUIDE FOR BEGINNERS

This guide explains how to set up the backend from zero.

1. Install the required software
- Install Node.js LTS from `https://nodejs.org/`
- Install PostgreSQL from `https://www.postgresql.org/download/`
- Install VS Code if you want an editor

2. Check Node.js is installed
- Open a terminal and run:
```powershell
node -v
npm -v
```

3. Open the project
- Open the folder `Feedback_1`
- Open a terminal inside the project

4. Go to the backend folder
```powershell
cd backend
```

5. Install backend packages
```powershell
npm install
```

6. Create the backend environment file
- Inside `backend`, create a file named `.env`
--Ive sent the file in whatsapp
- Copy this into it:
```env
PORT=5000
NODE_ENV=development
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/feedback_db?schema=public"
JWT_SECRET=replace-with-a-strong-secret
JWT_EXPIRES_IN=7d
CLOUDINARY_CLOUD_NAME=your-cloud-name
CLOUDINARY_API_KEY=your-cloudinary-api-key
CLOUDINARY_API_SECRET=your-cloudinary-api-secret
GOOGLE_CLIENT_ID=your-google-client-id
```

7. Edit the `.env` values
- Replace the PostgreSQL username, password, port, and database name in `DATABASE_URL`
- Replace `JWT_SECRET` with your own secret
- Fill in the Cloudinary values if you want document upload to work
- Fill in `GOOGLE_CLIENT_ID` if you want Google sign-in to work

8. Create the PostgreSQL database
- Create a database called `feedback_db`
- You can do this in pgAdmin or with SQL:
```sql
CREATE DATABASE feedback_db;
```

9. Generate Prisma client
```powershell
npm run prisma:generate
```

10. Run database migration
```powershell
npm run prisma:migrate -- --name init_auth
```

11. Start the backend
```powershell
npm run dev
```

12. Backend should now run on
- `http://localhost:5000`

13. Important backend features
- Authentication
- Role-based access
- Admin approvals
- Cloudinary document uploads
- PostgreSQL database with Prisma

14. Roles in this system
- `INDIVIDUAL`
- `NGO`
- `VENDOR`
- `RIDER`
- `ADMIN`

15. Roles that need admin approval
- `NGO`
- `VENDOR`
- `RIDER`

16. Useful backend commands
```powershell
npm install
npm run prisma:generate
npm run prisma:migrate -- --name init_auth
npm run prisma:studio
npm run prisma:validate
npm run dev
npm start
```

17. If something goes wrong
- Check PostgreSQL is running
- Check the values in `.env`
- Make sure the database exists
- Make sure `npm install` finished properly
- Make sure Cloudinary keys are correct if upload fails
